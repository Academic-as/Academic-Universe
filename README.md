# 🎵 Academic — Портфолио

Интерактивное портфолио музыканта и геймера **Academic** с поддержкой русского и английского языков.

## ✨ Особенности

- 🌐 **Двуязычность** — переключение RU/EN
- 🎵 **Фоновая музыка** — управляемый аудио-плеер
- 🎨 **Современный дизайн** — градиенты, blur эффекты, гладкие переходы
- 🎮 **Избранные игры** — три любимых гейма с описаниями
- 📺 **Видео-карусель** — 11 видео с YouTube
- 🔗 **Социальные ссылки** — Steam, Discord, YouTube, MyNickname, guns.lol
- 📱 **Адаптивный** — работает на всех устройствах

## 📁 Структура

```
.
├── index.html          # Главная разметка
├── script.js           # JavaScript (переводы, логика, рендеринг)
├── styles.css          # Стили (2000+ строк)
├── Art/
│   ├── Academic.jpg    # Аватар профиля
│   ├── icon.png        # Favicon
│   └── music/          # Фоновая музыка
└── README.md           # Этот файл
```

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Нажмите кнопку 🔊 для включения музыки
3. Используйте RU/EN для переключения языка
4. Нажмите "Узнать подробнее" для дополнительной информации

## 🛠️ Технологии

- **HTML5** — структура
- **CSS3** — стили и анимации
- **Vanilla JavaScript** — функциональность (без фреймворков)

## 📊 Контент

- ℹ️ **О себе** — 4 параграфа с информацией
- 🎮 **Любимые игры** — Zenless Zone Zero, NTE, GTA V
- 📹 **Видео** — 11 ремиксов и музыки
- 🔗 **Ссылки** — профили в соцсетях

## 🎨 Дизайн

- Цветовая схема: фиолет + розовый + белый
- Фоновые эффекты: blur, градиенты, тени
- Анимации: плавные переходы, слайды, hover эффекты

## 📝 Переводы

Все текста переводятся между РУ и EN через `data-i18n` атрибуты и объект `translations` в `script.js`.
